# Recovered assemblies

These files are decompilations of the public King and legacy RedUtils/RLBotDotNet assemblies from RLBotPack. They are reference material for the RLBot v5 port, not the final v5 source files.

The recovery workflow also extracts the matching RedUtils v4 and RLBotDotNet APIs used by King, to identify compatibility changes required for RLBot v5.
